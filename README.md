# LegacyDonuts
An unofficial dunkin Donuts app for ios 5+. This app is not affiliated with Dunkin Donuts. Use at your own risk. I am not responsible for any damages caused by this app. By using the app, you automatically agree to these terms and conditions.
# How does this work? 
The app was built from scratch, and after looking through the website logs of dunkin, I found the api. This allows the app to communicate with dunkin Servers.
